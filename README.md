<h1 align="center">BaseConverter</h1>

Conversor de bases numéricas desenvolvido em Java.

## Funcionalidades

- Conversão de binário para decimal e hexadecimal.
- Conversão de decimal para binário e hexadecimal.
- Conversão de hexadecimal para decimal e binário.
- Conversão de hexadecimal para binário e decimal.
- Validação de entradas.

### Tecnologias

- Java 17
- Maven
- JUnit 5
- jqwik

### Testes

O projeto utiliza testes unitários e testes de propriedades para verificar a consistência das conversões.

Para executar os testes:

mvn test

Como utilizar

Clone o repositório:

git clone github.com/Eri-ux209/base-converter

Entre na pasta:

cd base-converter

Compile o projeto:

mvn compile

### Objetivo

Projeto desenvolvido para praticar Java, manipulação de números, algoritmos de conversão e testes automatizados.
